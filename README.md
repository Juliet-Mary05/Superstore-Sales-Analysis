# Superstore-Sales-Analysis


  ## Project Overview

This project presents an exploratory data analysis of the Sample
Superstore dataset using Tableau.

## Business Objective

The objective is to analyze sales, profit, discounts, products,
regions, customer segments, shipping modes, and trends over time.

## Tools Used

- Tableau – Exploratory Data Analysis and visualization
- Microsoft Excel – Data checking and EDA notes
- GitHub – Project documentation and version control

## Analysis Performed

- Overall Sales, Profit and Quantity
- Regional Sales and Profit
- Category and Sub-Category Analysis
- Discount Analysis
- Profit Margin Analysis
- Customer Segment Analysis
- Sales and Profit Trends
- Sales vs Profit
- Discount vs Profit
- Quantity vs Profit
- Top 10 Products by Sales
- Bottom 10 Products by Profit
- Profit Outlier Analysis

## Key Findings

- Technology generated the highest sales and profit.
- Furniture had a substantially lower profit margin.
- Tables recorded the largest sub-category loss.
- West generated the highest regional sales and profit.
- Annual sales increased substantially by 2017.

## Recommendations

Further investigation is recommended for low-profit Furniture products,
loss-making Tables, and products with unusually negative profits.
